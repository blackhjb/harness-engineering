# python-service: Python 서비스 구현 규율

`backend-dev` 가 Python 태스크에서 여는 **하나의** 스택 스킬이다(1 디스패치 = 1 스킬).

## 계층과 경계

- `api/routes` → `application/services` → `integrations`·`domain` 단방향. 라우트는 HTTP 관심사만 — 비즈니스 규칙을 라우트에 넣지 않는다.
- **경계 입력만 검증한다**: 외부 API·사용자 요청은 pydantic 모델로 방어하고, 내부 함수 간 호출은 신뢰한다. 내부에 방어 코드를 겹겹이 쌓지 않는다.
- 의존성은 함수 인자 또는 FastAPI `Depends` 로 주입한다. 모듈 전역 싱글턴을 새로 만들지 않는다 — 이미 있으면 그 수명·스레드 안전성을 로그에 적고 쓴다.
- 응답 DTO는 내부 모델을 그대로 노출하지 않는다. 필드 추가는 하위 호환(추가형), 제거·rename 은 breaking 으로 취급한다.

## TDD 루프

1. RED — 기준을 인코딩한 실패 테스트. **assertion 실패**여야 한다(import·수집 오류는 red 가 아니다).
2. GREEN — 통과에 필요한 최소 구현, focused 테스트 실행.
3. REFACTOR — 중복 제거·이름 정리 후 재실행.
4. 종료 — 전건 스위트(`pytest -q`, 프로젝트가 지정한 인터프리터로) 실행하고 **수집 수·통과 수·실패 수를 값 그대로** 로그에 남긴다. 실패·xfail 로 종료 금지, 실패 테스트 삭제 금지.

## 테스트 3층

| 층 | 대상 | 도구 |
|---|---|---|
| 단위 | 순수 함수·정책·계산 | pytest, 픽스처는 파일 로컬 factory |
| 경계 | 라우트·클라이언트 | `TestClient` + `app.dependency_overrides`, 외부 HTTP 는 스텁 |
| 통합 | DB·캐시 왕복 | 실제와 같은 엔진(인메모리 SQLite 는 스키마 동등할 때만) |

- mock 경계를 **보고서에 명시**한다(무엇까지 실제로 돌았는지). 라우트 계약은 mock 이 아니라 실 라우트 호출로 판정한다.
- 비동기 코드는 이벤트 루프를 막지 않는지 확인한다 — 동기 I/O 는 `asyncio.to_thread` 로 감싸고, 그 사실을 **호출 형태로** pin 한다(소스 문자열 검색은 주석만으로도 통과해 가드가 되지 않는다).

## 마이그레이션·설정

- 스키마 변경은 버전 파일로만. 적용된 마이그레이션을 수정하지 않는다.
- 설정은 환경변수 + 기본값. 기본값은 **안전한 쪽**으로 둔다(기능 OFF·짧은 타임아웃).
- 타임아웃은 라이브러리 의미를 확인하고 적는다 — 예: httpx `timeout=3.0` 은 connect/read/write/pool **각각** 3초다.

## 관측·로그

- 로그에 사용자 입력 원문·식별자를 남기지 않는다. 건수·상태·소요만 남긴다.
- 예외를 삼키지 않는다. 폴백이 정책이면 그 폴백을 테스트로 pin 한다.

## 산출 계약

프로덕션 코드 + 테스트(스위트 green) + 필요한 마이그레이션 · 값이 담긴 로그 항목 · 위키 통찰(없으면 "없음" 명시) · 한국어 요약(태스크 ID, 만진 파일, 테스트 수치, 발견한 설계 공백).
